Uygulamaya Özel Şifre Oluştur

  1. Telefona veya bilgisayara git
  2. appleid.apple.com adresini aç
  3. Apple ID ile giriş yap
  4. "Oturum açma ve güvenlik" bölümüne git
  5. "Uygulamaya özel şifreler" → "+" butonuna bas
  6. Şifreye isim ver (örn. "iCloud Web")
  7. Üretilen xxxx-xxxx-xxxx-xxxx şifreyi kopyala
  8. Bu siteye geri dön ve şifre alanına yapıştır
